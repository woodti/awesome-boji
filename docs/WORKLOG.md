## 2026-10-15：页脚与课表往返体验

- 按站长截图反馈去掉页脚巨型 Boji 字标，缩小标题与留白，将导航排成两列，编辑说明、图片署名和版权集中对齐。页脚介绍文字明确设置白色，避免与深色底混在一起。
- 课表生成后将天数、器械、时长保留在 URL，可复制链接；刷新、查看动作后返回，仍是同一份课表。修改选项后需重新生成才允许下载、复制和打印，避免导出旧版本。文字下载也包含课表链接。
- 动作筛选只绑定按钮，不再把动作卡片当筛选按钮；点击动作要点不改变分类，锚点变化可重置筛选并展开目标，损坏的 URL 编码不会导致脚本中断。
- 真实浏览器验证三天哑铃二十分钟课表的生成、复制、动作往返、刷新；检查下载文件有相同选择与链接。动作筛选、展开与异常锚点检查通过。
- 页脚 390 / 768 / 1440 宽度无横向溢出，视觉检查通过。项目内 taste-skill 源码 lint 0 FAIL / 0 WARN，首页 inspector 0 FAIL / 2 WARN，保留已有无视频和字体尺寸数量说明。原设计方向不变，仅修正页脚比例与对齐。
- 本地格式、5 项核心测试、类型、构建与站内产物检查通过。正式发布以本提交对应 Actions 成功与线上检查为准。

每小时维护任务应先看本记录与 Git 状态，再检索资料、决定是否有值得修改的内容；不重复改已经处理的问题，不为发文频率制造内容。

# 首版产品与设计

## 目标

服务“听过薄肌，想知道怎么开始”的中文读者。先解决理解目标、安排第一周、看懂动作和饮食四件事。

首页主张：**写代码，也练薄肌。** 网站标题为 **Awesome Boji｜薄肌指南**，域名保留 lianboji.com。 对读者不承诺速成体型，不制造极低体脂目标。以动作、习惯和恢复作为长期内容方向。

## 信息架构

| 路由             | 读者任务                     |
| ---------------- | ---------------------------- |
| `/`              | 认识网站，选择自己的起点     |
| `/start/`        | 沿四步入门路径行动           |
| `/guides/`       | 按分类和关键词找知识         |
| `/guides/:slug/` | 阅读完整内容并核对来源       |
| `/plan/`         | 根据时间与器械生成入门模板   |
| `/movements/`    | 查看动作要点与降低难度的方法 |
| `/tools/`        | 计算参考范围、组间休息计时   |
| `/theory/`       | 了解话题原始内容与独立解读   |
| `/about/`        | 了解编辑原则、来源和反馈渠道 |
| `/privacy/`      | 了解输入与访问数据的处理     |

## 视觉

按项目级 taste-skill 的 `sentence-as-layout` 方向重做，白色、黑色与信号红；标题使用 Noto Serif SC，正文 Noto Sans SC。首屏用一句短句与哑铃实拍，把工作到训练的切换放在一起。

首页采用真实摄影、斜向照片组合、文字与图像的粘性阅读、文章列表、工具索引和问答，不使用装饰性编号、图标卡片、英文小标签或虚构的训练成绩。四张摄影的出处和许可在 `/credits/`，不代表站长或用户实录。图片均随站部署，字体也由 Fontsource 本地打包。

具体方向、两轮检查与截图复评见 `TASTE-REPORT.md`。

## 行为与数据

- 文章与默认课表直接生成 HTML，主要内容不依赖 JavaScript 渲染。
- 搜索、筛选、计算和计划生成在浏览器执行，不请求 AI 或后端 API。
- 身体输入和计划不持久化；刷新可恢复默认状态。
- 不增加账号、排行榜、购买按钮或虚构用户证明。
- 计划下载通过 Blob 生成 UTF-8 文本，打印样式隐藏无关导航。
- 尊重 `prefers-reduced-motion`，提供可见焦点、跳至正文链接、表单标签和弹窗关闭行为。

## 后续迭代方向

在验证流量与读者需求后再考虑：更完整的动作示意、内容日期独立维护、参考来源修订历史、读者主动授权的训练记录。若需要跨设备记录，应设计服务端持久化、数据删除与隐私范围，不能把浏览器存储当成账户数据库。

目前没有自动更新和定时抓取；“理论观察”由编辑人工维护，避免把未核对的热榜和二手观点直接发布。
